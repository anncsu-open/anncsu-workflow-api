# API examples

Runnable request examples for the `/v1` workflows, rendered from the
[Bruno](https://www.usebruno.com/) collection in `docs/api/bruno/`. Each example
carries a real request body, validation tests, and notes on the ANNCSU behaviour
it exercises — complementing the schema-level [API reference](../index.md).

The examples target the PDND **collaudo** (UAT) environment. Read-only searches are
safe to run; the creation and suppression flows are **write operations** (the
"Dry-run Accesso" pair creates then suppresses, netting to no live record).

This page is regenerated by hand from the Bruno GUI ("Generate documentation"),
then `scripts/refresh-api-examples.sh` repoints the viewer to the self-hosted
assets. Headless build-time regeneration is on the backlog.
