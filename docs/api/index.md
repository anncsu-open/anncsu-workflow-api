# API reference

Interactive reference of the `/v1` API contract, generated from the current code
at every documentation build. Use the selector in the top bar to switch the
schema language (English / Italiano) — the running service offers the same
selection on `/v1/openapi.json` via the `lang` query parameter or the
`Accept-Language` header.
